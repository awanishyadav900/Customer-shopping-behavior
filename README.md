# Customer-shopping-behavior:
🛒 Customer Shopping Behavior Analysis
📌 Overview
1. Analyzed customer shopping behavior using Python, and PostgreSQL.
2. Explored customer spending patterns, subscriptions, discounts, and product performance.
3. Performed data cleaning, preprocessing, and business analysis on 3,900+ customer records.
4. Built interactive dashboards and SQL queries to generate business insights.
🛠️ Technologies Used
# Python (Pandas, NumPy)
PostgreSQL & SQL
Matplotlib & Seaborn
📊 Key Insights
Subscribers generated higher revenue compared to non-subscribers.
Express shipping customers spent more on average.
Loyal customers contributed significantly to sales.
Discounts strongly influenced purchases for certain products.
🚀 Project Goal

The goal of this project is to help businesses understand customer purchasing behavior and make data-driven decisions through analytics and visualization.
